# NBA historical component benchmark (Nov26)

New read-only research module `nba_component_history.py` compares nine fixed prior-game methods for forecasting minutes, shot/free-throw/turnover opportunity proxy, net scoring per opportunity, peripheral points per minute and resulting FanDuel production. Four earlier complete played observations of the same NBA ID/team, target strictly later and before cutoff. All policies evaluated on identical target player-games, equal date weighting; no actual target minutes or starter status used by any prediction. The role-aware challenger uses last observed role only, not a claim about prelock confirmation. Incomplete or duplicate date windows rejected rather than skipping an intermediate observation. This is not official USG%, does not model playing probability or teammate injury effects, and is not an exact DFS forecast. Six synthetic tests added. Official historical acquisition and actual benchmark results pending private runner. No production scores changed.
