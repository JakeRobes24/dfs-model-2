The NFL empirical CRPS computation now uses sorted draws rather than allocating the full pairwise distance matrix. Mathematical identity gives the same empirical score in O(n log n) time and O(n) memory, permitting substantially larger simulation evaluation samples. Tests compare with the original formula including ties, negative values and seeded draws, and exercise 100,000 draws. This improves computational scaling, not evidence of predictive accuracy.
