# NFL candidate coverage safeguards

The original contest salary stays authoritative. A finite DAILY point estimate is not sufficient when a matched export reports a conflicting salary or roster layout, or an identity is ambiguous. Those issues now block the fixed-candidate research ranking and remain in the report. Missing identity with independently reviewed corroboration remains eligible for gap review (not automatic live scoring). A missing/unlabeled special-teams price is not treated as a numeric salary disagreement.

Classic and single-game candidate review now share the existing single-game diagnostic FD bounds of -30 to 150; finite negative values remain valid. These bounds are conservative review guards, not a statistical calibration or claim about all possible actual outcomes. An out-of-range baseline or independent consensus blocks ranking rather than clipping points. Explicit accepted-player coverage must equal the eligible contest count.

Five regression tests added. No production scoring, candidate selection, deployment or new source data.
